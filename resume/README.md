# Hunter Weeks — Resume

Redesigned, ATS-optimized resume and a 2026 job-search playbook.

## Files

- **`Hunter-Weeks-Resume.pdf`** — ready-to-send, single-page, text-based PDF (ATS-readable).
- **`hunter-weeks-resume.html`** — the editable source. Edit this, then re-export the PDF.
- **`RESUME-TIPS.md`** — research-backed guide on what makes employers pick you in 2026, with sources.

## Editing & exporting your own PDF

1. Open `hunter-weeks-resume.html` in any browser (double-click it).
2. Edit the text directly in the HTML if you want changes.
3. Print to PDF: **Cmd/Ctrl + P → Destination: Save as PDF → Paper: Letter → Margins: Default**. The page sets its own spacing, so don't add extra margins.
4. Save as `Hunter-Weeks-Resume.pdf`.

## Before you send it (quick checklist)

- Confirm every number is accurate (150+ projects, 5+ years, 100% retention, "up to 80%").
- Tailor the **Skills** and **Summary** to each job posting's wording (see `RESUME-TIPS.md`).
- Add a GitHub and/or LinkedIn link to the header if you have them.
- Copy-paste the PDF into a plain-text editor to confirm it reads in order (ATS test).

The design uses a warm terracotta accent (#c2410c) but stays single-column with
standard headings and real selectable text so applicant tracking systems parse it correctly.
